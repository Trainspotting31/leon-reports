调研日期 2026-10-12 morluto/rea v6.4.0

一、它是什么

一句话：REA 是给 AI 编程助手（Claude Code / Codex / Cursor 等）装的一个「逆向工程工具箱」——通过 MCP 协议，让 AI 能调用 Ghidra / IDA / Hopper 这些专业逆向工具，替你拆软件、解释功能怎么工作、甚至为你的项目复刻类似功能。

它把「逆向工程」这门原本属于安全研究员的硬手艺，打包成了一行命令：npx rea-agents setup。你不需要会装 IDA、不需要懂反汇编，对 AI 说一句「弄清这个 App 的搜索功能怎么工作」，剩下的它自己干。

二、爆火背景

10 月初，一批老游戏突然能在浏览器里直接玩：《光环》《半条命》《暗黑破坏神》，甚至 3A 大作《GTA5》《使命召唤：现代战争 2》。最出圈的案例是一位开发者让十几个 Claude Code 智能体并行，把一款射击游戏 99% 的函数还原成 C++ 源码，其中 83% 编译后与原程序逐字节一致。

REA 是这波「AI 逆向」浪潮里名字最响的一个，但不是技术的开创者——GhidraMCP、IDA Pro MCP 去年就有了。REA 真正的贡献是把门槛降到零，让普通人也能用。

四、工作原理（架构）

你 ──→ AI 助手 (Claude / Codex / Cursor / Gemini / Grok / OpenCode ...) │ MCP 协议 ▼ REA 服务器 (Node.js / TypeScript) │ 调用本地工具 ▼ Ghidra / IDA / Hopper / JADX / Playwright / pwntools │ 返回 ▼ 证据 + 结论（每个结论附 evidence）

核心设计特点

  • 本机运行：被分析的软件不离开你的电脑，分析在本地进行
  • 证据驱动：每个结论都附带证据和局限性，不是凭空猜测
  • 工具编排：一个 MCP 服务器把 20 多种逆向工具统一起来，AI 自己选工具
  • 支持 Hermes：package.json 里有 verify-hermes-client.mjs，官方就适配了 Hermes Agent

五、质量评估

工程化程度极高，不是炒概念的玩具。测试套件极其完整——verify-ghidra-swift、verify-evm-interface、verify-go-binary 这类真实逆向验证脚本有几百个。作者做了大量真实二进制测试，覆盖 MIPS/Swift/DOS/COM/NativeAOT 等冷门架构。这是一个有真实投入的项目。

六、能力边界（重要）

安全圈口碑：AI 拆程序是真的，但有天花板。
  • ✅ 没加壳 / 轻度加壳：AI 轻松拿下
  • ⚠️ VMP 等高强度虚拟化保护：啃不动，模型会卡住
  • ❌ 服务器端的逻辑：永远拆不到——你能拆自己电脑上的客户端，拆不开别人机房里的那一半
逆向教材《Practical Reverse Engineering》合著者 Elias Bachaalany 的评价就一个词：炒作——同类工具早就有了。

七、法律与合规风险

这是最容易被忽视、但风险全在用户身上的部分。
  • 「研究/学习」豁免，「重建/复刻」不豁免：中国《著作权法》第五十条豁免「研究」，但 REA 宣传语里的「为你的项目复刻类似功能」找不到法律豁免
  • 净室原则被绕过：传统净室开发要求「拆的人」和「写的人」隔一堵墙。REA 让同一个 AI 既读反编译结果又写新代码，中间没墙——Hacker News 上有人称之为「洗知识产权」
  • 数据外发：分析在本地跑，但智能体要把反编译片段发给模型服务商理解。拆客户/签 NDA 的软件，这一步本身就违约
  • 游戏公司已光速反击：Rockstar、Activision、Bethesda 法务都下架了自家游戏的浏览器版
免责声明把责任全推给用户——REA 只提供工具，「取得授权、遵守法律」是你的事。

八、对你的实际意义

1. 豆包沙箱逆向：技术可行，但要先探测

你沙箱里的 mcp_vm_server 是 Go 编译的二进制，正是 REA src/go 模块专门支持的。但先别急着上 REA——建议先花 2 分钟探测：

# 沙箱回来后先跑这两条
file /runtime/mcp_vm_server/mcp_vm_server
strings mcp_vm_server | grep "main\." | head -20

如果 Go 二进制带符号表（main. 前缀的函数名能扒出来），根本不用 REA——go tool objdump 或 strings 就够。只有符号被 strip 了，才值得动用 REA 这套重家伙。

2. 可借鉴的架构思路

REA 本身是个教科书级的「MCP 服务器 + 工具编排」范例——一个服务器统一调度 20+ 外部工具，AI 自主选择调用顺序。你以后想给 Hermes 接复杂工具链，可以直接参考它的模块划分（domain / services / adapters / composition 分层）。

3. 知识产权保护的启示

逆向圈老手的结论对做产品的人最有价值：「只要程序跑在用户手里，就能被拆开，唯一稳妥的办法是把关键逻辑放到服务器上。」——这跟你做 acpbj.cn 一个道理：SSG 前端谁都能看，所以数据和业务逻辑都留在服务器端。

九、结论

维度判断
技术实力真实、工程化程度高，非概念炒作
